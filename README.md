# Real_Time_Object_Detection_Using_Yolo
This project demonstrates how to perform real-time object detection using a webcam with YOLOv8 and OpenCV in Python.

🔍 Features

Real-time object detection using YOLOv8

Webcam input with adjustable resolution

Easy to customize with your trained YOLO model

🧰 Requirements

Python 3.8+

ultralytics

OpenCV

🛠️ Installation

1.Clone the repository:

```
git clone https://github.com/yourusername/yolov8-webcam-detection.git
cd yolov8-webcam-detection

```

2.Install dependencies:
```
pip install ultralytics opencv-python
```
3.Download or place your YOLOv8 model (.pt file) in the project directory. You can use a pretrained one (yolov8m.pt) or your own trained model.
